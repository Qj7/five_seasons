# Magic Shoes

Мобильный магазин Crocs и Jibbitz в стиле Unicorn-приложения.

**Live:** https://qj7.github.io/magic_shoes/

## Запуск

```bash
npm install
npm run dev
```

Каталог: Classic Clog, BAPE × Crocs, Naruto × Crocs, Jibbitz и топ-20 популярных моделей.

## Сборка

```bash
npm run build
npm run preview
```

## GitHub Pages

Пуш в `main` → GitHub Actions собирает сайт и публикует его. Ветку переключать не нужно.

Один раз в репозитории (если ещё не сделано):

1. **Settings → Pages → Build and deployment → Source:** GitHub Actions  
   (не «Deploy from a branch»)

После этого каждый пуш в `main` обновляет https://qj7.github.io/magic_shoes/
