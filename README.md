# Magic Shoes

Мобильный магазин Crocs и Jibbitz в стиле Unicorn-приложения.

**Live:** https://qj7.github.io/magic_shoes/

## Запуск

```bash
npm install
npm run dev
```

Каталог: Classic Clog, BAPE × Crocs, Naruto × Crocs, Jibbitz и топ-20 популярных моделей.

## Сборка

```bash
npm run build
npm run preview
```

## GitHub Pages

Деплой идёт автоматически через GitHub Actions при пуше в `main`.

Один раз в репозитории:

1. **Settings → Pages → Build and deployment → Source:** GitHub Actions
2. Запушьте `main` (или запустите workflow вручную: Actions → Deploy to GitHub Pages → Run workflow)

Сайт будет доступен по адресу `https://qj7.github.io/magic_shoes/`.
